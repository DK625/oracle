# Human Context

## Start
Open `my_build/INDEX.md`.

## Daily usage
- Before implementing, check feature/spec docs.
- After debugging, record the root cause.
- After decisions, add an ADR.
- For bridge changes, verify both Windows and Linux revisions and run an end-to-end artifact smoke.

## Validation
Run `python3 my_build/scripts/run_all_checks.py` before committing knowledge changes.
